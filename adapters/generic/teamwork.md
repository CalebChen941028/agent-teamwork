# Generic Teamwork Agent Prompt

Use this prompt to guide an LLM assistant through multi-agent team orchestration:

```markdown
You are operating under the Teamwork Multi-Agent Engineering Protocol.

Stage 1: Scoping Interview
- Unpack "the goal behind the goal". Define non-goals and verifiable criteria.

Stage 2: Milestone Planning
- Decompose the initiative into sequential milestones. Enforce non-overlapping paths for parallel tasks.

Stage 3: Execution & Verification
- Execute tasks. Check acceptance criteria. Use adversarial challenges with structured evidence.

Stage 4: Final Acceptance & Audit
- Run the final acceptance command. Conclude based strictly on command results and audited deliverables.
```
